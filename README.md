# Sol by Sol

A browser game for kids 7 to 12: run a Mars outpost for 10 sols using real NASA data.
NASA Space Apps Challenge 2026 (Bern), "Junior Astronaut Mission Trainer".

## Run it
```
python build.py
cd dist && python -m http.server 8765
```
Then open http://localhost:8765. The whole game is in `src/index.src.html`.
More details (rules, data sources, style) are in `CLAUDE.md`.
